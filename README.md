# Simple Todo List

A lightweight to-do list app built with vanilla HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Persist tasks in local storage
- Clean and responsive interface

## Run locally

Open `index.html` in your browser.

## Project structure

- `index.html` – app structure and logic
- `README.md` – project overview

## React improvement ideas

This project can be upgraded into a more scalable React app with these ideas:

- Split the app into reusable components such as `TodoForm`, `TodoList`, and `TodoItem`
- Use React state and hooks to manage tasks more cleanly
- Add task editing, filtering, and sorting options
- Handle persistence with a custom hook using `localStorage`
- Add animations and better UI states for completed tasks
- Introduce categories, priorities, and due dates
- Use React Router for a multi-page task dashboard
- Add tests with React Testing Library for task behavior
- Improve accessibility with keyboard support and better labels
